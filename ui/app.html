El proyecto

La investigación detrás de TertulIA

Un sistema multiagente diseñado para democratizar el análisis de viabilidad de negocios locales.

01 · La problemática

Abrir un negocio local es una apuesta a ciegas

El 50% de los negocios locales cierran en los primeros dos años. La principal causa no es la falta de esfuerzo, sino la falta de información: un estudio de viabilidad profesional cuesta miles de euros y semanas de espera, fuera del alcance de la mayoría de emprendedores.

Los datos existen en OpenStreetMap, registros del Ayuntamiento de Madrid y portales inmobiliarios, pero están dispersos y requieren horas de cruce manual para convertirse en una decisión útil. TertulIA automatiza ese proceso de principio a fin.

02 · Los cinco agentes

Cinco roles especializados que trabajan en secuencia

Cada agente tiene un objetivo concreto y no puede inventar datos: si una cifra no tiene fuente o cálculo reproducible, la marca como «sin dato» y la confianza del veredicto baja automáticamente.

  • Investigador La Portera Consulta OpenStreetMap vía Overpass API para obtener competidores reales en un radio de hasta 2 km, con nombre, dirección, horario y URL de cada local.
  • Especialista Visual Berto Analiza fotos del entorno y la competencia para detectar oportunidades que los datos estructurados no capturan.
  • Analista El Chulapo Calcula el punto de equilibrio y los márgenes usando únicamente cifras con fuente o cálculo reproducible.
  • Redactor El Pregonero Convierte los hallazgos en un informe estructurado con semáforo verde/ámbar/rojo y motivos concretos.
  • Revisor La Revisora Comprueba cada afirmación contra las fuentes y devuelve el informe al Redactor si hay contradicciones, hasta un máximo de 3 rondas.
03 · La arquitectura técnica

LangGraph + CrewAI + MCP + datos abiertos

El grafo de LangGraph controla el flujo completo: orquesta los cinco nodos en secuencia, gestiona el bucle de revisión Redactor–Revisor (máx. 3 rondas) y pausa el grafo antes de generar el PDF para que el analista humano revise y apruebe. Si la aprobación no llega en 24 horas, el estudio expira automáticamente (ERR-009).

Los datos geográficos llegan a través de un servidor MCP propio que consulta OpenStreetMap mediante la Overpass API (© OpenStreetMap contributors, licencia ODbL). Cada fuente queda registrada con su URL, fecha exacta de consulta y herramienta usada. La confianza del veredicto se calcula con una fórmula fija: parte de 1,0 y descuenta 0,10 por cada dato faltante y 0,05 por cada fuente sospechosa de inyección de prompt.
